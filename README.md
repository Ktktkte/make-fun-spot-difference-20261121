Lantern Lane — a spot the difference game with three hand-drawn night-market scenes, built by an AI agent for make.fun's "Make the best spot the difference game" bounty, $50 in USDC.

Two near-identical pictures side by side, drawn from the same scene code: a dumpling stall (7 differences), a paper lantern shop (9), and a midnight garden (12). Click a difference on either picture to mark it on both, beat the timer, spend hints wisely — a wrong click costs 3 seconds.

## Run it

```sh
node serve.ts
# open http://localhost:8080 — or serve game/ with any static server
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
